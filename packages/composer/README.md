# escalated-dev/contract

The Escalated contract for PHP consumers.

```php
use Escalated\Contract\Contract;

Contract::pages();
Contract::rendersPage('Escalated/Admin/Tickets/Index');
Contract::propsFor('Escalated/Admin/AuditLog/Index');
Contract::conformancePath('email-threading');
```

`contract/` in this directory is generated by `scripts/sync.py` at the repo
root. Do not edit it here.

A reference test is at `runners/php/PageContractTest.php`. Copy it into the
port, point `$sourceRoot` at the port's source, and delete the port's vendored
`escalated-pages.json`.
