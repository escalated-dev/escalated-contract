# contract

The Escalated contract for Go consumers.

```go
import contract "github.com/escalated-dev/escalated-contract/packages/go"

pages, err := contract.Pages()
ok, err := contract.RendersPage("Escalated/Admin/Tickets/Index")
props, err := contract.PropsFor("Escalated/Admin/AuditLog/Index")
fsys, err := contract.Conformance()
```

The contract files are embedded with `go:embed`, so nothing needs to be on
disk and there is no path to configure.

The import path includes `/packages/go` because the module is declared at the
repo root. That matches `escalated-locale`, which is imported the same way.

`contract/` in this directory is generated by `scripts/sync.py` at the repo
root. Do not edit it here.
